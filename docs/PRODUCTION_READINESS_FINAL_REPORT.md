## 🔴 الفجوات الحرجة (P0) - يجب إصلاحها قبل الإطلاق

### 1. إدارة التبعيات والثغرات الأمنية (40/100) 🚨

**المشكلة:**

- **16 ثغرة أمنية** مكتشفة (7 عالية الخطورة، 8 متوسطة)
- ثغرات في حزم حساسة: `vite`, `axios`
- عدم وجود ملف `pnpm-lock.yaml` في Git

**الإجراء المطلوب:**

```bash
# 1. إصلاح الثغرات
pnpm audit --fix

# 2. تحديث الحزم المتأثرة يدوياً
pnpm update vite axios --latest

# 3. إضافة ملف القفل إلى Git
git add pnpm-lock.yaml
git commit -m "chore: add pnpm lockfile for reproducible builds"
```

**الوقت المقدر:** 30 دقيقة

### 2. معالجة الأخطاء المالية - آلية التسوية (75/100) 🚨

**المشكلة:**

- **غياب آلية التسوية (Reconciliation)** بين السجلات المالية و Stripe
- حقول `balanceBefore` و `balanceAfter` في Ledger غير مستخدمة
- لا يوجد اختبارات للعمليات المالية المعقدة

**الإجراء المطلوب:**

1. إنشاء `server/jobs/reconciliation.job.ts`
2. تفعيل حقول تتبع الرصيد في Ledger
3. إضافة اختبارات تكامل للتسوية

**الوقت المقدر:** 4-6 ساعات
