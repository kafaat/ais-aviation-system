## حدود الدليل

- تنزيل عائلة Refunds من المتصفح لا يملك حالة مخصصة في ملف التقارير الحالي؛ وظائفه الخلفية مشمولة بقبول SQL السابق.
- عزل المستأجرين وأدوار finance/ops في صادرات التقارير مثبت بقبول SQL/tRPC السابق، وليس لكل رحلة تنزيل متصفح. فحص توقيع PDF لا يثبت غياب محتوى المستأجر الآخر.
- التنفيذ يخص مجموعة CI المختارة على Chromium؛ لا يثبت تشغيل جميع ملفات E2E أو جميع المتصفحات المعرّفة.
- لا يمنح هذا الدليل قبولًا للإنتاج أو لمزودي الطيران الخارجيين أو لجميع أمثلة Videcom العامة أو لتقارير المورد التي يزيد عددها على 200.
